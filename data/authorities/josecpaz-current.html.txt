				    <p>Gobierno</p>
<p><strong>SE LLEVARON ADELANTE LA FIRMA DE 154 ESCRITURAS DE VIVIENDAS PARA VECINOS DE JOSÉ C. PAZ</strong></p>
<p>&nbsp;</p>
<p>José C. Paz, viernes 20 de noviembre 2036.- En el Teatro Municipal de José C. Paz se realizó una nueva jornada de regularización dominial mediante la cual 154 familias paceñas concretaron la firma de las escrituras de sus hogares, garantizando de forma definitiva la seguridad jurídica sobre sus propiedades.</p>
<p>El acto estuvo encabezado por la intendente interina de José C. Paz, Lic. <strong>Lorena Espina</strong>, y el secretario de Gobierno, <strong>Juan Pablo Mansilla</strong>, junto a la escribana adscripta <strong>Claudia Defelitto</strong>, representante de la Escribanía General de Gobierno del Ministerio de Justicia y Derechos Humanos de la Provincia de Buenos Aires. También formó parte de la mesa de autoridades la directora general de Casa de Tierras municipal, <strong>Elba Benítez</strong>.</p>
<p>Luego de la instancia protocolar, el senador provincial e intendente en uso de licencia por José C. Paz, Dr. H.C. <strong>Mario Alberto Ishii</strong>, se acercó al recinto para saludar y acompañar personalmente a las familias presentes. Su visita tuvo un significado especial, ya que gran parte de los vecinos beneficiarios accedieron a sus hogares años atrás a través de las primeras cooperativas de construcción impulsadas durante su gestión, cerrando hoy un ciclo histórico con la obtención del título de propiedad.</p>
<p>La ceremonia comenzó con la entonación del Himno Nacional Argentino y contó con la participación de secretarios y secretarias del Departamento Ejecutivo, autoridades del Consejo Escolar, medios de comunicación y cientos de vecinos.</p>
<p>Durante las alocuciones, las autoridades destacaron el trabajo mancomunado entre el Estado municipal y el provincial para sostener políticas públicas de acceso gratuito a la escrituración social. Tras la firma simbólica en el escenario junto a cuatro vecinos beneficiarios, se procedió a la rúbrica de la totalidad de las 154 escrituras.</p>
<p>De esta manera, la gestión local reafirma su compromiso de acompañar el desarrollo urbano y social del distrito, respaldando el esfuerzo de las familias trabajadoras de José C. Paz desde la construcción de sus viviendas hasta la titularidad definitiva de su patrimonio.</p>

  function parseCSV(texto) {
    const filas = [];
    let fila = [];
    let valor = "";
    let dentroComillas = false;

    for (let i = 0; i < texto.length; i++) {
      const char = texto[i];
      const next = texto[i + 1];

      if (char === '"' && dentroComillas && next === '"') {
        valor += '"';
        i++;
      } else if (char === '"') {
        dentroComillas = !dentroComillas;
      } else if (char === "," && !dentroComillas) {
        fila.push(valor);
        valor = "";
      } else if ((char === "\n" || char === "\r") && !dentroComillas) {
        if (valor !== "" || fila.length > 0) {
          fila.push(valor);
          filas.push(fila);
          fila = [];
          valor = "";
        }
      } else {
        valor += char;
      }
    }

    if (valor !== "" || fila.length > 0) {
      fila.push(valor);
      filas.push(fila);
    }

    return filas;
  }

  function renderPaginacion() {

      }
    };
    paginacion.appendChild(siguiente);
  }
